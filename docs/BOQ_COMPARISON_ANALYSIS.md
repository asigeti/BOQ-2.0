## 7. רשימת שיפורים נדרשים

### 7.1 מבנה היררכי (עדיפות: קריטית)

- [ ] הוספת תמיכה ב"תת כתב" (sub-document)
- [ ] הוספת תמיכה בפרקים מרובים
- [ ] הוספת תתי-פרקים עם סיכומי ביניים
- [ ] יצירת עמוד ריכוז למכרז

### 7.2 תיאורי פריטים (עדיפות: גבוהה)

- [ ] הוספת הפניות לתקנים (ת"י)
- [ ] פירוט סוג חומר (ב-30, פ-W500, וכו')
- [ ] תיאורים טכניים מפורטים יותר

### 7.3 מטא-דאטה (עדיפות: בינונית)

- [ ] הוספת שם חברה/מזמין
- [ ] הוספת מספר פרויקט
- [ ] הוספת שם מנהל פרויקט
- [ ] הוספת סימון "חסוי" (אופציונלי)

### 7.4 פורמט PDF (עדיפות: בינונית)

- [ ] עמוד ריכוז עם סיכומים לפי פרקים
- [ ] סיכומי ביניים בסוף כל תת-פרק
- [ ] סיכום כללי בסוף כל פרק
