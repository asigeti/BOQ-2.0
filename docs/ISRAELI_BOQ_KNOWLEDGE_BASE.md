## What is BOQ?

### Definition

**BOQ (Bill of Quantities)** - **כתב כמויות** in Hebrew - is a comprehensive document used in construction projects that itemizes all materials, parts, and labor (along with their quantities and costs) required to complete a construction project.

### Purpose in Israeli Construction

1. **Tender Documentation**: Forms the basis for contractor bidding
2. **Cost Estimation**: Enables accurate project costing
3. **Contract Basis**: Serves as the contractual agreement for work scope
4. **Progress Payments**: Used for calculating interim payments
5. **Variation Management**: Baseline for measuring changes
6. **Final Account**: Basis for final project settlement

### Key Stakeholders

| Role (Hebrew) | Role (English) | BOQ Responsibility |
|---------------|----------------|-------------------|
| יזם | Developer/Owner | Commissions BOQ |
| אדריכל | Architect | Provides design drawings |
| מהנדס | Engineer | Structural/MEP specifications |
| כלכלן בניין | Quantity Surveyor | Prepares BOQ |
| קבלן ראשי | Main Contractor | Prices and executes |
| קבלן משנה | Subcontractor | Executes specific trades |
| מפקח | Supervisor | Verifies quantities |

## הספר הכחול - Official Blue Book

### Overview

**המפרט הכללי לעבודות בנייה** ("הספר הכחול" - The Blue Book) is the official Israeli construction specification document published by the **Interministerial Committee for Standardization** (הוועדה הבין-משרדית לסטנדרטיזציה). It defines uniform measurement methods and specifications for preparing BOQ and estimates.

**Official Website**: https://mifratclali.mod.gov.il/

### Committee Composition

The committee was established in the early 1980s and includes representatives from:
- **משרד הביטחון** (Ministry of Defense)
- **משרד הבינוי והשיכון** (Ministry of Construction and Housing)
- **משרד האוצר** (Ministry of Finance)
- **משרד התחבורה** (Ministry of Transport)

### Blue Book Chapter Structure

Each chapter in the Blue Book contains:

1. **הגדרות מפרטיות** - Specific definitions for that trade
2. **דרישות ביצוע** - Execution requirements and quality standards
3. **שלביות עבודה** - Work sequencing and staging
4. **אופני מדידה** - Methods of measurement (critical for BOQ)
5. **תשלום** - Payment terms and what's included

### Key Principle: Methods of Measurement

"The manner in which quantities are measured is defined in Israel by the General Specifications for Building Works (הספר הכחול), with each specification containing a chapter named 'Methods of Measurement' (אופני מדידה)."

This standardizes:
- What's included in each item price
- How to measure quantities (gross/net)
- Deduction rules for openings
- Overlap and waste considerations

### Dekel Item Code Structure

Each item in מחירון דקל has a unique code:

```
Format: XX.YY.ZZZ.WW

XX    = Chapter number (פרק)
YY    = Sub-chapter (תת-פרק)
ZZZ   = Item sequence number
WW    = Variant/size code

Example: 02.03.015.10
         02 = פרק 02 (בטון)
         03 = תת-פרק (יציקת בטון)
         015 = Item number (concrete pour)
         10 = Variant (specific thickness/type)
```

## Measurement Units

### Standard Israeli BOQ Units

| Unit Code | Hebrew | English | Use Case |
|-----------|--------|---------|----------|
| מ"ר | מטר רבוע | Square Meter | Flooring, painting, plastering |
| מ"א | מטר אורך | Linear Meter | Pipes, cables, skirting |
| מ"ק | מטר קוב | Cubic Meter | Concrete, excavation, fill |
| יח' | יחידה | Unit/Each | Doors, windows, fixtures |
| ק"ג | קילוגרם | Kilogram | Steel reinforcement |
| טון | טון | Ton | Structural steel |
| קומפ' | קומפלט | Complete Set | Kitchen, bathroom sets |
| גלובלי | גלובלי | Lump Sum | Fixed price items |
| מ"ר נטו | מטר רבוע נטו | Net Square Meter | Excluding openings |
| מ"ר ברוטו | מטר רבוע ברוטו | Gross Square Meter | Including openings |

### Unit Conversion Common Issues

```python
# Common conversions in Israeli construction
1 דונם (dunam) = 1,000 מ"ר
1 טון = 1,000 ק"ג
1 מ"ק בטון ≈ 2,400 ק"ג (approximate weight)
1 מ"ק בטון requires ≈ 80-120 ק"ג זיון (reinforcement)
```

### Measurement Rules

#### For Areas (מ"ר)
- **Flooring**: Measured to finished walls (net area)
- **Painting**: Measured including openings < 0.5 מ"ר
- **Plastering**: Deduct openings > 1.0 מ"ר
- **Waterproofing**: Include upstands and laps

#### For Volumes (מ"ק)
- **Excavation**: Measured in bank (before swell)
- **Fill**: Measured in compacted state
- **Concrete**: Net volume excluding reinforcement

#### For Linear (מ"א)
- **Pipes**: Measured center-line, fittings counted separately
- **Cables**: Include drops and risers
- **Skirting**: Deduct for door openings

### Item Description Requirements

A complete BOQ item description must include:

1. **What** (מה) - The work/material
2. **Where** (איפה) - Location in building
3. **How** (איך) - Method/specification
4. **Standard** (תקן) - Applicable Israeli standard
5. **Inclusions** (כולל) - What's included in price
6. **Exclusions** (לא כולל) - What's priced separately

### Example Complete Description

```hebrew

## מוריה BOQ Format Standard

### Overview

The **מוריה** (Moriah) format is a professional Israeli BOQ standard used for government tenders and official construction documents. It defines:
- Specific column order for RTL display
- Hierarchical numbering system
- Summary page structure (ריכוז למכרז)

### Standard Column Order (RTL Display)

For Hebrew documents displayed right-to-left:

```
| מספר סעיף | תאור הסעיף | יח' | כמות | מחיר | סה"כ |
|-----------|------------|-----|------|------|------|
| Item No.  | Desc.      | Unit| Qty  | Price| Total|
```

**Column widths (typical)**: 12% | 45% | 8% | 10% | 10% | 15%

### 4-Level Hierarchy Structure

מוריה BOQ uses a 4-level hierarchy:

```
Level 1: תת כתב (Sub-Document)      → X
Level 2: פרק (Chapter)               → X.Y
Level 3: תת פרק (Sub-Chapter)        → X.Y.Z
Level 4: סעיף (Item)                 → X.Y.Z.NNNN

Example: 1.3.2.0015
         │ │ │ └── Item sequence (0015)
         │ │ └──── Sub-chapter (2)
         │ └────── Chapter (3)
         └──────── Sub-document (1)
```

### Item Numbering Format

```
Format: X.Y.Z.NNNN

X    = Sub-document code (1-9)
Y    = Chapter/פרק code (1-21)
Z    = Sub-chapter/תת פרק code (1-99)
NNNN = Sequential item number (0001-9999)

Examples:
1.1.1.0010  = First sub-doc, Chapter 01, Sub-chapter 1, Item 10
1.3.2.0015  = First sub-doc, Chapter 03, Sub-chapter 2, Item 15
2.6.1.0001  = Second sub-doc, Chapter 06, Sub-chapter 1, Item 1
```

## Pricing Methodology

### Price Build-Up Method

```
Base Material Cost (עלות חומר בסיס)
+ Labor Cost (עלות עבודה)
+ Equipment Cost (עלות ציוד)
+ Waste Factor (אחוז פחת) - typically 3-10%
+ Transport (הובלה)
= Direct Cost (עלות ישירה)

+ Site Overhead (תקורת אתר) - typically 8-12%
+ Head Office Overhead (תקורה כללית) - typically 5-8%
+ Profit (רווח) - typically 8-15%

## Calculation Methods

### Area Calculation Methods

#### Method 1: Net Area (שטח נטו)
```
Net Area = Gross Area - Openings
Used for: Flooring, waterproofing
```

#### Method 2: Gross Area (שטח ברוטו)
```
Gross Area = Length × Width (including openings)
Used for: Formwork, ceiling area
```

#### Method 3: Wall Area
```
Wall Area = Perimeter × Height - Openings
Opening deduction rules:
- Openings < 0.5 מ"ר: No deduction
- Openings 0.5-3.0 מ"ר: Deduct 50%
- Openings > 3.0 מ"ר: Full deduction
```

### Concrete Calculation

```python
# Slab concrete
volume = length * width * thickness

# Beam concrete
volume = width * height * length

# Column concrete
volume = cross_section_area * height

# Foundation
volume = length * width * depth + haunch_volume
```

### Reinforcement Calculation

```python
# Standard reinforcement ratio (kg per m³ of concrete)
ratios = {
    "יסודות": 80-100,   # Foundations
    "עמודים": 150-200,  # Columns
    "קורות": 120-150,   # Beams
    "תקרות": 80-100,    # Slabs
    "קירות": 60-80      # Walls
}

reinforcement_weight = concrete_volume * ratio
```

### Formwork Calculation

```python
# Slab formwork (bottom only)
formwork_area = slab_area

# Beam formwork (3 sides)
formwork_area = (2 * height + width) * length

# Column formwork (4 sides)
formwork_area = perimeter * height

# Wall formwork (2 sides)
formwork_area = 2 * length * height
```
